# MockTest Master

Build a responsive Testbook-like mock test web application. Include an admin dashboard to create and delete tests with positive and negative marking, a student test interface with a countdown timer and auto-submit, and an end-of-test scorecard showing score, accuracy, rank, percentile, and a Chart.js comparison graph against other students.

This project was built with [Lovable](https://lovable.dev).
